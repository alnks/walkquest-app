## НАЧАЛО ПРОМТА

Ты работаешь в проекте WalkQuest (папка walkapp) — мобильное приложение для прогулок с механикой «тумана войны» на карте.

**Проектные скилы, которые обязательно используй:**
- `walkquest-design` — контекст проекта, дизайн-сессии и утверждённые решения. Если нужны детали макетов или архитектуры — ищи их там сам, не задавай мне уточняющих вопросов по контексту проекта. Если информации в скиле нет — прими разумное решение и зафиксируй его в отчёте.
- `walkquest-qa` — верификация изменений на эмуляторе/устройстве перед сдачей.

**Организация работы — строго в два этапа:**
1. **Сабагент (coder)** реализует все правки Б1–Б6. Перед кодом — разобраться в текущей реализации соответствующих модулей, не ломать соседнюю логику.
2. **Ты (основной агент)** — верификация и контроль качества: прогоняешь `walkquest-qa` по каждому исправленному сценарию на эмуляторе. Без подтверждённой верификации пункт не считается закрытым.

**Ограничения по ресурсам (соблюдай строго):**
- Минимум сборок: группируй правки по модулям (карта/трекинг, таймер, геолокация, статистика, навигация) и собирай пакетно.
- Один цикл «сабагент → верификация → точечные доработки», без многократных итераций.
- В финальном отчёте по каждому пункту: статус (готово/частично/не удалось) + чем верифицировано. Не удалось — честно напиши причину.

### Функциональные баги

**Б1. Прогресс тропы стирается при повторном прохождении.** Прошёл по тропе — она открылась; вернулся той же дорогой — снова ушла в туман. Повторное прохождение по уже открытому пути не должно затуманивать его обратно. Проверить логику объединения/пересчёта геометрии открытых сегментов.

**Б2. Таймер прогулки.** Подсчёт времени багуется: таймер обновляется «сам по себя», с нерегулярной переодичностью. Привести к стабильному обновлению раз в секунду, на основе фиксированных меток старта/паузы/стопа, а не накопленного хаотичного интервала.

**Б3. Геолокация.** Определяет местоположение долго, но точка появляется сразу при нажатии «начать прогулку»; во время прогулки местоположение теряется и долго висит плашка «Определяю местоположение». Устранить: единый поток геоданных между «до старта» и «во время прогулки», корректная переподписка/резолв при потере сигнала, плашка — только при реальном отсутствии фикса и с таймаутом восстановления.

**Б4. Статистика — раздел «Планы».** Работает некорректно: любое выбранное время помечается выполненным, а заданное время само меняется (ставишь 16:30 — становится 22:30). Заодно ПОЛНОСТЬЮ убрать раздел «Планы» из статистики — без мёртвого кода и недостижимых экранов.

**Б5. Невозможно выйти из настроек.** Зайти в настройки из профиля — назад не выйти: табы (рейтинг, прогресс, карта) кликабельны, но поверх остаётся окно настроек; системная стрелка назад выключает приложение. Выход возможен только по «Готово». Исправить стек навигации.

**Б6. Навигация «назад».** Все переходы по системной стрелке назад должны возвращать на предыдущий экран, а не закрывать приложение. Проверить все экраны: профиль, настройки, статистика, задания, онбординг-флоу.

### Критерии сдачи

1. Каждый пункт Б1–Б6 закрыт или в отчёте честно помечен, почему не закрыт.
2. Каждый пункт проверен на эмуляторе/устройстве через walkquest-qa (скрин/лог прогона — в отчёте).
3. Удалённый раздел «Планы» не оставляет мёртвого кода и ломающих ссылок.
4. Ничего не задето вне списка: основной экран карты, онбординг, дизайн-элементы — без регрессий.
