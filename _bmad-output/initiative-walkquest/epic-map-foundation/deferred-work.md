### Правки, потребовавшиеся для зелёного прогона

1. **`local.properties`** — `sdk.dir` переведён на прямые слэши (`C:/Users/Lenovo/...`):
   AGP `SdkLocator.validateSdkPath` падал с IOException «Синтаксическая ошибка в имени файла»
   на Windows-пути с одинарными `\`.
2. **`gradle/libs.versions.toml`** — откат androidx на линию, совместимую с пином spine
   AGP 8.13.2 / compileSdk 36: composeBom `2026.09.00 → 2025.11.01` (Compose 1.9.5 + material3 1.4.0),
   coreKtx `1.19.1 → 1.18.0`, lifecycle `2.11.0 → 2.10.0`, activityCompose `1.13.0 → 1.12.4`.

   («AGP 9 не использовать»). AGP/Kotlin/Gradle не тронуты.
3. **`data/fog/FogGrid.kt`** — в KDoc-комментарии `android.*/MapLibre` преждевременно закрывал
   блок `/* */` (последовательность `*/`); переписано как «без android.* и MapLibre».
4. **`data/poi/Poi.kt`** — `category.replace('=', ': ')`: двухсимвольный char-литерал;
   заменено на строковый вариант `replace("=", ": ")`.
5. **`data/packages/PackageInstaller.kt`** — `install()`: добавлен `return` перед `try`
   (try-expression было statement'ом → «Missing return statement»).
6. **`data/fog/FogRepository.kt`** — `FogJson`: добавлен `encodeDefaults = true`.
   Без него kotlinx.serialization опускал `order = "row-major, lsb-first"` (значение по
   умолчанию) из заголовка `.fog`-файла — формат на диске не соответствовал контракту

   `com.sun.net.httpserver.HttpServer` на минимальный `ServerSocket`-сервер (приватный
   `MiniHttpServer` в том же файле): модуль `jdk.httpserver` не виден kotlinc при компиляции

8. **`data/packages/TestPackages.kt`** — приоритет операторов: `"""a""" + """b""".toByteArray()`

   конкатенация обёрнута в скобки в `metaJson()` и `manifestJson()`.
9. **Имена тестов с `:`** (Kotlin 2.3 запрещает `:` в backtick-именах для JVM): двоеточия

   (2 шт.), `PoiFilterTest`, `RealBoundariesPointInPolygonTest`.
10. **`PointInPolygonTest.kt` (RegionLocatorTest)** — ошибка в тестовых данных: точка
    `(59.45, 30.0)` («между bbox регионов») на самом деле внутри прямоугольника-полигона

## Релизная конфигурация AD-8 — 2026-10-04

Закрытие AD-8 для гейта 1.12: целевой артефакт — release arm64 APK ≤ 30 МБ.

### Конфигурация (`app/build.gradle.kts`, buildType `release`)

- `isMinifyEnabled = true` + `isShrinkResources = true` (R8 full mode по умолчанию AGP 8.x).
- **ABI через `ndk { abiFilters += "arm64-v8a" }` внутри `release`**, а не `splits.abi`:
  фильтр действует только на релиз, debug остаётся universal (77,3 МБ — характеристика
  debug, не гейт-артефакт). Выбран один артефакт arm64 вместо матрицы splits —
  проще для гейта; armeabi-v7a/x86 добавятся позже, если появится потребность.
- **Подпись: `signingConfig = signingConfigs.getByName("debug")`** — для замера размера
  достаточно debug-подписи (подпись на размер APK практически не влияет). APK проверен
  `apksigner verify --print-certs`: подписан, CN=Android Debug. Настоящая
  release-подпись (keystore автора, Play Signing) — HITL автора, отдельно.
- Правила R8 в `app/proguard-rules.pro`: стандартный набор kotlinx.serialization
  (keep `**$$serializer`, `Companion`, `serializer(...)`), keep пользовательского
  `OsmIdSerializer`, страховочный `-keep class org.maplibre.**` + сохранение имён
  native-методов (JNI), keep `kotlin.Metadata`.

### Остаточные риски (проверить на устройстве перед гейтом 1.12)

1. **R8 мог отрезать лишнее.** Правила ProGuard написаны без прогона на реальном
   устройстве. Перед гейтом установить release APK на arm64-устройство и проверить:
   рендер карты (MapLibre/JNI — самый вероятный кандидат на падение), сериализацию
   fog/settings/track journal/пакетов (чтение-запись JSON), фильтры POI.
2. **Debug-подпись в release.** Для реальной выкладки нужен release-keystore автора
   (HITL): заменить `signingConfig` и не коммитить keystore/пароли в репозиторий.
3. **Только arm64-v8a.** Эмуляторы x86_64 и старые armv7-устройства не получат
   релизный APK. Если потребуется — перейти с `abiFilters` на `splits.abi`
   с `universalApk false` (или App Bundle `.aab` для Play, где ABI-сплит делает
   Google Play).
