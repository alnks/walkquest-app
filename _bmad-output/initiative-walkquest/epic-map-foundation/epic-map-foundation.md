# Карта, туман и пакет региона

## Description

Платформенный эпик: пустой репозиторий превращается в приложение, где карта домашнего региона лежит под туманом, а туман расступается от реального перемещения. Сюда входят: scaffold проекта (Kotlin + Compose + MapLibre по AD-1/AD-10), скрипт `region-pack`, собирающий пакет СПб+Ленобласти из OSM и Википедии (AD-6), битовые карты тумана и честный процент по проходимым тайлам (AD-4, AD-9), POI-маяки, модель мульти-региона и офлайн-работа (AD-2). Эпик — гейт AD-8: он обязан измерить и подтвердить числовые пороги на реальном устройстве до старта зависимых эпиков.

## Outcome

Будущий пользователь впервые открывает город под туманом и может расступить его своей прогулкой; сигнал — пороги AD-8 подтверждены измерениями на устройстве среднего сегмента (путь к SM-4).

## Done when

1. Приложение устанавливается и офлайн показывает карту СПб/Ленобласти в тумане с плавным зумом и поворотом.
2. Записанный трек расступает туман только по проходимым тайлам; проход вокруг квартала не открывает двор (FR-1, FR-2).
3. Процент открытия считается по проходимым тайлам из пакета и един для всех экранов (AD-4).
4. POI видны сквозь туман, карточка с описанием открывается офлайн (FR-18).
5. Пакет региона скачивается, проверяется по `formatVersion` и контрольным суммам, весит ≤ 50 МБ.
6. На устройстве среднего сегмента измерены и подтверждены: ≥ 30 fps с туманом, ≤ 5% батареи/час фоновой записи, APK ≤ 30 МБ (AD-8).

## Boundaries

Scaffold приложения, карта/туман/POI, скрипт генерации пакетов, хостинг пакетов. Не входит: полировка трекинга (автопауза, батарейный страж, финальный экран) — epic-walk-tracking; достижения и задания — epic-achievements-quests.
