# Достижения и задания

## Description

Мотивационный слой поверх карты: 40 достижений из контент-каталога (исследование, регулярность, дистанция, задания, путешествия; 6 rare-моментов с праздником) и 22 задания из пула — случайная раздача или выбор из 6, одно активное за раз, выполнение на честном слове, отказ и замена без штрафа.

## Outcome

У прогулки всегда есть повод и награда: пользователь видит условия неполученных достижений и прогресс к близким; сигнал — SM-2 (привычка) и доля прогулок с финальным экраном (SM-5).

## Done when

1. Все 40 достижений каталога выдаются по своим условиям; условие проверяется после каждой завершённой прогулки; новые достижения из обновлений выдаются задним числом по истории.
2. Процентные достижения считаются по городу, районные — только в городах с районами (модель территории, AD-9).
3. Неполученное достижение показывает условие; у близких — полоску прогресса; rare отмечается праздником, обычные — тихой карточкой.
4. Задания раздаются из полного пула случайно и выбором из 6; одно активное за раз; замена активного — через подтверждающий диалог без штрафа.
5. Кнопка задания скрывается в настройках; выполненные задания учитываются в статистике и условиях достижений (D2, D3).
6. Все тексты соответствуют каталогу и голосу продукта (коротко, на «вы», без стыда).

## Boundaries

Domain-правила достижений и пула заданий, экраны прогресса и заданий, карточка на финальном экране. Не входит: балансировка весов пула по статистике отказов (после запуска, см. каталог «Открытые вопросы»).
