# Лидерборд

## Description

Соревновательный слой без компрометации приватности: рейтинг по расстоянию и проценту открытия с вкладками «Город» и «Друзья», ник при первом открытии, друзья по ссылке-приглашению. Бэкенд — Supabase Free (AD-7): участники, агрегаты по регионам, дружеские связи; Row Level Security; на сервер уходят только ник и агрегированные цифры (AD-3).

## Outcome

Оля безопасно соревнуется с городом и друзьями, не раскрывая маршруты; сигнал — социальная JTBD закрыта, приватность подтверждена проверкой трафика.

## Done when

1. Ник запрашивается при первом открытии лидерборда, не при онбординге; участие отключаемо.
2. Вкладки «Город» (текущий регион) и «Друзья» показывают расстояние и процент открытия.
3. Друг добавляется по ссылке-приглашению; принятие приглашения отмечается (D5).
4. Агрегаты отправляются при завершении прогулки и по ручному обновлению; офлайн — отложенная отправка при появлении сети.
5. Проверкой трафика подтверждено: сервер не получает координаты, треки, историю (AD-3).
6. RLS включена: пользователь может писать только свою строку агрегатов.

## Boundaries

Экран рейтинга, Supabase-проект (таблицы, RLS, приглашения), клиентская синхронизация агрегатов. Не входит: раздача пакетов регионов (AD-6), любые другие серверные данные.
