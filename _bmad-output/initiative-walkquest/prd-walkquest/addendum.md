**Выводы для позиционирования:**
- Ниша подтверждена, но русскоязычный Android-сегмент слабо закрыт — окно возможности.
- Ключевая развилка жанра: «карта путешествий» vs «свой город пешком». WalkQuest — второе.
- Частая жалоба в жанре: приложения, считающие транспорт и езду, обесценивают карту. Лимит скорости WalkQuest — прямой ответ.
- Приватность (локальное хранение) — сильный маркетинговый аргумент: Fog of World этим продаётся 14 лет.

Источники: fog-breaker.com (обзоры жанра, сентябрь 2026), mwm.ai (метрики сторов), play.google.com, rustore.ru, fogofworld.app, vas3k.club (обсуждение ниши, 2021).

## Roadmap-парк (v2+, не входит в MVP)

- Фото пользователей у локаций с лёгкой модерацией (+ доступ к камере).
- Погодные подсказки в напоминаниях («возьмите зонт») — интеграция погодного API.
- Слой заведений: поесть, кофе, туалет, укрытие от непогоды; подборки заведений по районам.
- Слой «открытые улицы»: процент по уличной сети поверх тайлов (модель Citystrides).
- Челленджи с фото внутри приложения (когда появится камера).
- iOS-версия, дополнительные языки.
- Монетизация (модель не выбрана; решение после SM-1/SM-2).

## Технические заметки для архитектуры

- Карта и проходимость: OpenStreetMap (дорожная сеть, тропинки, границы городов); вода/лес/промзоны и пешеходно-недоступные магистрали исключаются из знаменателя процента.
- Тайловая сетка: размер тайла — открытый вопрос (OQ-2), решать на прототипе; баланс точности и объёма данных.
- Анти-чит: фильтрация по скорости между соседними валидными точками + отброс телепортаций; точные пороги — полевые тесты (OQ-1).
- Энергопотребление: батчинг GPS-точек, адаптивная частота по скорости движения; фоновый сервис Android с foreground-уведомлением.
- Лидерборд-сервер: минимальный — ник + агрегированные метрики; координаты не принимает.
- Перенос данных: экспорт/импорт файла (формат выбрать на этапе архитектуры).
