# Сверка «макет ↔ реализация» — WalkQuest

Дата: 2026-10-15 (финальная сверка стори 7.14 эпика design-alignment: все 12 экранов
в обеих темах; экранные стории 7.1–7.12 и sweep 7.13 завершены, склейки пересобраны).
Устройство прогонов: эмулятор `Medium_Phone_API_37.0`, debug-сборка app-debug.apk,
пакет региона `spb-city/v6` (`wq.py seed-package`).

**Метод.** Макет — отрендеренный утверждённый HTML (`mockups/*.html`, headless Edge,
2×) в `_mock/`. Реализация — скриншоты приложения в эмуляторе (`wq.py` + uidump/
input tap; чистая установка → онбординг → вкладки → прогулка с паузой/удержанием
«Завершить» → replay треков → POI). Склейка «МАКЕТ слева / РЕАЛИЗАЦИЯ справа» —
Pillow, `_qa/compare-stitch.py`; каноничные склейки —
`_qa/emulator-run/compare-verify/<id>-<theme>.png` (26 файлов: 12 экранов × 2 темы,
плюс 04 онбординг пошагово s1–s4 в обеих темах).

## Осталось (решения владельца 2026-10-17 — все 10 закрыты)

1. **FAB «К моей точке» — ОСТАЁТСЯ.** Макет его не рисовал (недосмотр макета, признан
   владельцем); spec §1 его специфицирует. Реализация корректна, макет считается
   переутверждённым: FAB «К моей точке» — часть продукта.
2. **Иконки нижней навигации — текущие векторы.** Решение владельца: семантические
   векторы (pin/столбики/флажок/персона) лучше макетных глифов-плейсхолдеров ◈◎▦◉.
   Макетные глифы не утверждаются.
3. **Ручной выбор темы — ДЕЛАЕТСЯ (решение 2026-10-17): три варианта — тёмная,
   светлая, системная.** Реализуется отдельной сторёй (персист настройки, пилюля
   «Тема» в Настройках с выбором, применение без пересоздания активности). После
   реализации этот пункт закрывается повторной сверкой 11-settings.
4. **Эмодзи-значки достижений/заданий — отдельной задачей позже** (согласовано
   2026-10-17). Полный перевод значков на векторы — отдельная дизайн-задача;
   записано в deferred-work.md.
5. **Даты в истории заданий — в поздних версиях** (2026-10-17), при необходимости —
   расширение QuestStateStore таймстампами.
6. **Онбординг офлайн без манифеста — специальный сценарий не нужен** (2026-10-17).
   Текущее поведение (выход через «Пропустить», регион — карточкой на карте) остаётся.
7. **«Автозавершение при разряде» — НЕ делаем** (2026-10-17); в поздних версиях
   добавим. Отмечено в deferred-work.md; строка в макете настроек не реализуется.
8. **Живая проверка рейтинга — ВЫПОЛНЕНА 2026-10-17 (чтение ✅, вступление ❌).**
   Прогон боевого клиентского кода на эмуляторе против живого облачного Supabase
   (проект `jxfegrxylimrmbhcflqa`, сид-данные 4 пользователей). Читающая часть
   работает: топ отрисовывает живые строки с «км · %», сегмент «Друзья» — пустое
   состояние, «Обновить» — успешный перезапрос без notice. Скриншоты:
   `_qa/emulator-run/compare-verify/raw/08-rating-live-*.png`; отчёт
   `epic-design-alignment/story-7.17-rating-live-verify.md`.
   **Новое открытое решение (вне эпика, скоуп эпика 5): вступление с ником
   блокируется RLS боевого проекта** — клиент ходит с anon-ключом без Auth,
   `POST /profiles` → 42501 row-level security. Варианты: (1) anonymous sign-ins
   Supabase + `signInAnonymously()` на клиенте (рекомендовано, RLS не трогаем);
   (2) ослабить RLS под v1; (3) рейтинг read-only до отдельной стори.
   Тестовые «Тестер_*» оставлены в облаке, cleanup-SQL — в шапке seed-миграции
   `supabase/migrations/20261017090000_seed_rating_test.sql`.
9. **Поправка spec §1 про RegionProgressBadge — сделана оркестратором** (2026-10-17):
   строка о плашке удалена из screens-spec.md §1, зафиксировано решение AL-11.
10. **Жёлтый штрихованный круг на карте во время записи — НА ПАУЗЕ** (2026-10-17):
    владелец проверит сама после правок; если повторится — расследование слоя карты.
    Описание для проверки: экранно-закреплённый круг ~40px, жёлтая диагональная
    штриховка, красная точка по краю; в Compose-оверлее отрисовки нет; замечен при
    снятии 02п-светлой (7.13) с пилюлей «+ Задание» на экране.
