# WalkQuest — Experience Spine

## Foundation

Одна поверхность: нативный Android, русский язык. UI-система не наследуется — визуальная идентичность полностью своя, см. `DESIGN.md` (токены, палитра, типографика). Платформенные конвенции Android соблюдаются: системный жест «назад» (свайп от края, predictive back — работает на каждом экране), foreground-уведомление при трекинге, динамический размер шрифта. Тёмная и светлая темы следуют системной настройке; тёмная — первоклассная.

Главные ограничения из PRD, формирующие весь опыт: управление одной рукой на ходу; приложение не требует постоянного внимания к экрану (музыка в наушниках важнее); прогресс показывается честно.

## Information Architecture

| Поверхность | Откуда попадают | Назначение |
|---|---|---|
| Онбординг (4 экрана) | Первый запуск | Обучение → домашний регион → цель → доступ к геолокации |
| Карта | Запуск, вкладка | Туман, POI, старт прогулки, панель статистики и планировщика |
| Карточка POI | Тап по маяку на Карте | Название и описание точки интереса |
| Прогулка | Кнопка «Начать прогулку» | Запись трека, минимум информации, «＋ Задание» |
| Финал прогулки | «Завершить», автопауза+завершение, батарея 10% | Награда: похвала, %, статистика, достижения, «поделиться» |
| Прогресс | Вкладка | Статистика / Достижения / Задания (сегменты). Каждый вход во вкладку открывает Статистику — выбранный ранее сегмент не запоминается между заходами |
| Случайное задание | Прогресс → Задания | «Вытянуть карту» → карточка с «Принять / Ещё раз» |
| Выбор из 6 | Прогресс → Задания | Сетка 6 карточек с описаниями → «Принять задание» |
| Рейтинг | Вкладка | Лидерборд «Город» / «Друзья»; первый вход → выбор ника |
| Регионы | Профиль → «Мои регионы» | Список посещённых регионов, просмотр их карт |
| Планировщик | Карточка на панели Карты | Список запланированных прогулок: создать, перенести, удалить |
| Профиль | Вкладка | Цель, тема, режим по умолчанию, перенос данных, приватность |
| Настройки | Шестерёнка на Карте + пункт в Профиле | Все переключатели; два входа намеренно |

Нижняя навигация — 4 вкладки (Карта · Прогресс · Рейтинг · Профиль). Модальных стеков глубже одного уровня нет. «Назад» — системным жестом свайпа от края и явными кнопками-выходами («Не сейчас», «На карту»); стрелок в шапках нет — верх экрана недосягаем на ходу.

→ Состав компоновок (все экраны — тёмная и светлая тема рядом): `mockups/map-duo.html` (карта, прогулка, финал), `mockups/progress-tasks-duo.html` (прогресс, достижения, задания), `mockups/remaining-screens.html` (POI, рейтинг, регионы, профиль, настройки), `mockups/onboarding-duo.html` (онбординг). При конфликте спина важнее макета.

## Voice and Tone

Микрокопия. Голос бренда и визуальный характер — в `DESIGN.md`.

| Да | Нет |
|---|---|
| «Город под туманом» | «Fog of war» / военная лексика |
| «Неделя подходит к концу, а до плана 2 прогулки. Погуляем?» | «Вы отстаёте от цели!» |
| «Сделали перерыв или забыли остановить прогулку?» | «Прогулка всё ещё активна» |
| «Возвращайтесь завтра — впереди ещё столько открытий» | «Вы провалили серию» |
| «Информация о ваших передвижениях не покидает телефон» | «Треки не синхронизируются» (жаргон) |
| «Задания помогут разнообразить вашу прогулку. Их выполнение необязательно :)» | «Выполните задание для получения бонуса» |
| Короткие человечные фразы, на «вы» | Канцелярит, стыдящие формулировки, КАПС |

Продуктовые термины в интерфейсе: «Достижения» (не «ачивки»), «Задания» (не «челленджи»), «Регион», «Туман». Рабочие термины команды в интерфейс не попадают.

## Component Patterns

Поведенческие. Визуальные спецификации — в `DESIGN.md.Components`.

| Компонент | Поверхность | Правила поведения |
|---|---|---|
| Тогл режима | Карта, левый верхний угол | Только значки. Смена режима → микро-анимация всадника с подписью режима (~2.4с). Режим выбирается до старта; на экране прогулки тогла нет. TalkBack: contentDescription «Режим: пешком / вело» |
| Панель главного экрана | Карта | Статичная, не выдвигается: статистика мини-колонками + планировщик + CTA. Подробности — во вкладке Прогресс, регионы — Профиль → «Мои регионы» |
| Кнопка «Начать прогулку» | Карта, нижняя треть | Единственная акцентная заливка экрана |
| Карточка POI | Карта | Маяки видны сквозь туман, но в тумане не кликабельны (тап → подсказка «дойдите до точки»). Растуманенная точка пульсирует — намёк на кликабельность; тап открывает карточку в нижней зоне. После прочтения точка становится кольцом (прочитано, можно перечитать). Точки видны и на экране прогулки — как путеводные огни. Контент из локального кеша — работает офлайн |
| Экран прогулки | Прогулка | Карта максимальна; цифры — одна нейтральная строка; «＋ Задание» — кнопка-призрак; управление внизу: запись идёт — «Пауза» крупная акцентная, на паузе — «Продолжить» крупная акцентная; «Завершить» в обоих состояниях — меньшая кнопка-призрак с подтверждением удержанием: при удержании кнопка заполняется акцентом за ~600мс, раннее отпускание откатывает заполнение; текстовых подсказок-подписей нет, механика читается анимацией (защита от случайного обрыва на ходу). Чип состояния: «Идёт запись» — акцентный, «На паузе» — нейтральный, без свечения. Постоянное уведомление трекинга несёт текстовый статус: время и км (читается TalkBack и с заблокированного экрана) |
| Автопауза | Прогулка | 15 мин неподвижности → пауза; движение → автопродолжение; ещё 15 мин → уведомление-напоминание |
| Батарейный страж | Прогулка | 15% → предупреждение; 10% → автозавершение с финальным экраном |
| Финальный экран | Финал | Без названия района (скриншот безопасен для шеринга); игривая только герой-цифра; «Поделиться», «На карту»; весь экран влезает без прокрутки — никаких подписей-постскриптумов |
| Задания | Прогресс → Задания | Одно активное задание за раз; новое не берётся, пока текущее не выполнено/не отказались; выполнение на честном слове одним нажатием |
| Задания из прогулки | Прогулка → «＋ Задание» | Открывают поток заданий ПОВЕРХ прогулки; запись не останавливается. «Принять» и «Не сейчас» возвращают именно на экран прогулки, а не во вкладку |
| Случайное задание | Отдельный экран | «Вытянуть карту» в нижней зоне пальца; раздача (~350мс) замещает кнопку карточкой; в карточке только «Ещё раз» (пересдача); «Принять задание» — акцентная CTA, прибита к нижней зоне пальца, под ней «Не сейчас» — выход |
| Достижения | Прогресс → Достижения | Секции «Полученные» / «Неполученные», сворачиваемые; у неполученных — условие получения; у близких — полоска прогресса |
| Планировщик | Отдельная поверхность | Список запланированных прогулок; создание по модели будильника: день недели (Пн–Вс чипами) + время, без даты и года — горизонт планирования неделя; перенос, удаление свайпом с подтверждением. Пропуск без штрафа |
| Лидерборд | Рейтинг | Вкладки «Город» (текущий регион) / «Друзья»; ник запрашивается при первом открытии; участие опционально; текущий пользователь подсвечен |

## State Patterns

| Состояние | Поверхность | Поведение |
|---|---|---|
| Первый запуск | Онбординг | 4 экрана, без кнопки «пропустить» (обучение — один экран, остальное — обязательная настройка) |
| Офлайн | Везде | Карта, трекинг, растуманивание, статистика, POI из кеша работают; рейтинг ждёт сеть — тихо, без баннеров |
| Нет разрешения на геолокацию | Карта | Туман не расступается; объяснение и кнопка «Разрешить» при попытке старта |
| GPS-сбой / транспорт | Прогулка | Точки отсекаются лимитом скорости молча; пользователь узнаёт правило из обучения и анимации тогла |
| Потеря процесса | Прогулка | Запись восстанавливается без потери трека после убийства процесса системой |
| Пустая история | Прогресс | «Здесь появятся ваши прогулки — начните с карты» + ссылка на Карту |
| Рейтинг: ник не задан | Рейтинг | Первый вход: «Придумайте ник — так вас увидят другие» + поле ввода; можно закрыть и не участвовать |
| Рейтинг: нет друзей | Рейтинг → Друзья | «Пока здесь только вы. Пригласите друга по ссылке» + кнопка шеринга |
| Рейтинг: офлайн | Рейтинг | Последний кеш + пометка «данные на [время]», обновится при сети |
| Пользователь скрыт из рейтингов | Рейтинг | Видит таблицу, себя — без ранга, с подписью «вы скрыты; включите участие в настройках» |
| Регион загружается | Карта | Прогресс скачивания на карточке региона; трекинг не прерывается, растуманивание применится после загрузки |
| Пустой планировщик | Планировщик | «Запланируйте первую прогулку — напомним собраться» + CTA |
| Разряд батареи | Прогулка | 15% предупреждение → 10% автозавершение с сохранением |

## Interaction Primitives

- Тап — действие; системный свайп от края — назад (везде); свайп вниз по карточке POI — закрыть.
- Ключевые действия — в нижней трети экрана (зона большого пальца).
- Долгое нажатие не используется для критичных действий.
- Анимации короткие (≤400мс) и несут смысл: раздача карты, всадник режима. Единственная «длинная» — всадник (2.4с), и она обучающая.
- Уведомления в прогулке — тихий канал, без звука поверх музыки.
- **Запрещено:** карусели, принудительные пропуска заданий, стыдящие стрики, кнопки «назад» в верхнем левом углу, любые обязательные соцмеханики.

## Accessibility Floor

Поведенческая часть. Контрасты и цвета — в `DESIGN.md` (минимум 4.5:1; dim-тексты: тёмная тема #8D83A6, светлая #6E6384).

- TalkBack: каждый интерактивный элемент подписан (роль + состояние); тогл режима — «Режим: пешком / вело»; карта имеет текстовое описание прогресса («открыто 17,4% региона»).
- Растуманивание не анонсируется по тайлам (шум); TalkBack слышит итог на финальном экране и по запросу на панели статистики.
- Тач-зоны ≥48dp, зазоры между ними ≥8px. Компактный визуал иконки (шестерёнка, тогл режима) не означает компактную тач-зону: hit-area ≥48dp всегда, даже если глиф меньше.
- Динамический размер шрифта системы поддерживается; герой-цифры масштабируются без обрезки.
- Reduce Motion: всадник и раздача карты заменяются мгновенной сменой состояния; туман расступается мгновенно, без анимации.
- Прогулка полностью управляется без чтения экрана: старт/пауза/стоп крупные, состояние дублируется постоянным уведомлением с текстом (время, км).
- Приложение работоспособно при отключённых уведомлениях — они усиление, не несущая конструкция.

## Inspiration & Anti-patterns

- **Взято у карт-приложений (Google/Яндекс):** выдвижная нижняя панель поверх полноэкранной карты — пользователю не нужно учиться.
- **Взято у карточных игр:** «раздача» задания — короткая анимация вместо мгновенной подмены; предвкушение — часть механики.
- **Отвергнуто — кнопка «назад» в шапке (типичный паттерн):** недосягаема одной рукой на ходу; системный жест справляется.
- **Отвергнуто — стрики со стыдом (Duolingo-стиль):** серия показывается, но пропуск не наказывается и не шумит.
- **Отвергнуто — средневековая стилизация конкурентов:** квест ≠ свиток.

## Responsive & Platform

Одна платформа (Android), один класс устройств (телефон, портрет). Целевой эталон — Samsung Galaxy S26 (базовый), средний сегмент Android 10+. Раскладки держат системные вставки (жестовая навигация, чёлки) и крупный системный шрифт. Планшеты и горизонталь — не цель v1.

## Key Flows

Маппинг на сценарии PRD указан в заголовках.

### Flow 1 (реализует UJ-1) — Вечерняя прогулка (Оля, 28, будний вечер, скучно)

1. Оля открывает приложение → Карта: туман, статистика колонками, карточка «Завтра, 12:00».
2. Тап «Начать прогулку» (пеший режим уже стоит) → телефон в карман.
3. Идёт; туман расступается; музыка не прерывается.
4. Кофейня 30 минут → автопауза на 15-й минуте, автопродолжение при выходе.
5. Тап «Завершить».
6. **Кульминация:** финальный экран — «Отличная прогулка!», 17,4% крупно, новое достижение, «Поделиться результатом».

Отказ: села в автобус → лимит скорости молча не засчитал участок; пришла домой без «Завершить» → автопауза + напоминание через 15 минут.

### Flow 2 (реализует UJ-2) — Первый запуск (Оля, только установила)

1. Приветствие: «Город под туманом», правило режимов.
2. «Где вы живёте?» → регион определён по геолокации → «Это мой регион».
3. Цель: тип + значение степпером → «Выбрать».
4. «Доступ к геолокации» → «Разрешить и открыть карту».
5. **Кульминация:** весь город в тумане — масштаб игры виден физически.

Отказ: геолокация не дана → карта открывается, но при первом старте снова честное объяснение.

### Flow 3 (часть UJ-1, механика заданий) — Задание на прогулку (Оля, хочет разнообразия)

1. Прогресс → Задания: инструкция, два действия.
2. «Случайное задание» → «Вытянуть карту» → раздача → карточка «Пять фиолетовых вещей».
3. «Принять» → задание активно (одно за раз).
4. На прогулке отметила «Выполнено».
5. **Кульминация:** задание в «Выполненных», дата, ощущение маленького приключения.

Отказ: не получилось → «Отказаться» без штрафа; передумала до взятия → «Не сейчас» или свайп назад.

### Flow 4 (реализует UJ-4) — Поездка в Псков (Оля, выходные)

1. Приложение видит новый город → предложение загрузить регион.
2. Карточка региона показывает прогресс загрузки; трекинг не прерывается.
3. Три дня прогулок, туман Пскова расступается.
4. Дома: основная карта — домашний регион; Псков — в списке регионов со своим процентом.
5. **Кульминация:** коллекция регионов растёт — путешествия оставляют след.

### Flow 5 (реализует UJ-3) — Запланированная прогулка (Оля, боится забыть выйти завтра)

1. Карта → карточка планировщика → «＋» → дата и время («завтра, 12:00») → сохранить.
2. Карточка на панели показывает ближайшую: «Завтра, 12:00 — прогулка по плану».
3. Завтра в 11:45 — напоминание «пора собираться».
4. Оля выходит, тап «Начать прогулку» — план отмечен выполненным.
5. **Кульминация:** план сработал без усилия; серия жива.

Отказ: не вышла → прогулка помечается пропущенной без штрафа и без обрыва серии; перенос или удаление — в Планировщике свайпом.
