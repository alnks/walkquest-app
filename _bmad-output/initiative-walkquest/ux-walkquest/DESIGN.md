## Brand & Style

WalkQuest выглядит как вечерний город под мягкой лавандовой дымкой. Дизайн-стойка: современно, спокойно, взросло. Туман — не мрачный и не военный, а интригующая завеса: «за ним что-то есть, иди посмотри». Лавандовый туман (#B29ED1) — фирменный элемент бренда, он же опознавательный знак на иконке и в маркетинге.

Контраст характеров: спокойная палитра и типографика текста (DM Sans) против плотных игривых цифр прогресса (Nunito 1000). Праздник дозируется: Rubik Bubbles появляется только в редких моментах триумфа — закрытый район, юбилей. Ежедневный финальный экран прогулки обходится Nunito: радость каждый день не должна кричать.

Сознательные «нет»: не детский дизайн, не крупные яркие 3D-элементы, не средневековая стилизация (пергамент, руны, готика — у конкурентов), не «бежевый однотон». Тёмная тема — основная (целевой пользователь живёт в тёмной теме Samsung), светлая — полноценная вторая, обе следуют системной настройке.

Сезонные палитры — фича v2 (весна = эта лавандовая, лето = «Белые ночи», осень = терракота/хвоя, зима = петроль/кирпич). Поэтому v1 строится строго на семантических токенах: ни один hex не прошит в компонентах, только ссылки на роли.

## Colors

- **Туман (fog, `#B29ED1`)** — лавандово-молочная завеса. Только слой карты и бренд-элементы. Не цвет текста и не фон кнопок.
- **Акцент фисташковый (`#C6E26B` dark / `#7A9A1F` light)** — действие и прогресс: «Начать прогулку», активный режим, значения метрик, POI-маяки, полоски прогресса. Один акцент на экран — одна главная кнопка. Роли в светлой теме разведены строго: `#7A9A1F` — только графика (прогресс-бары, маркеры, рамки, графы); акцент **текстом** — `accent-text` `#587110` (5.05:1); **главная кнопка** — «призрак»: белая заливка + рамка 1.5px и текст `#587110` (утверждено на сравнении вариантов, 2026-09-30). Белый или тёмный текст на заливке `#7A9A1F` — запрещены, оба не читаются.
- **Сливовые поверхности (dark: `#191423` → `#231B33` → `#2C2248`)** — глубина без чистого чёрного; тёплый фиолетовый оттенок держит «вечерний» регистр.
- **Карта (dark: `#241C36`/`#2C2240`)** — всегда чуть светлее фона приложения, чтобы раскрытые просветы читались как «земля», а туман — как плёнка над ней.
- **Чернила (dark):** primary `#EFEAf7`, secondary `#B3A6C9`, dim `#8D83A6`.
- **Чернила (light):** primary `#241C33` для текста; заголовки смягчены до сливового `#4A3F66` — почти-чёрный на белом читался слишком строго; dim `#6E6384` (затемнён после проверки контраста — 4.5:1 на светлом фоне).

## Typography

- **display: Nunito 1000** — герой-цифры (17,4% на Прогрессе и финальном экране). Плотные, округлые, радостные.
- **heading: Nunito 800** — заголовки экранов и названия карточек.
- **body: DM Sans 400/500** — весь читаемый текст, уведомления, описания заданий. Спокойный, нейтральный, отлично держит кириллицу и длинные русские слова.
- **celebration: Rubik Bubbles** — только редкие праздники (см. Brand & Style). «Туманный» характер шрифта — фирменная специя, не повседневность.
- Минимальный кегль интерфейса — 12px. Динамический размер шрифта системы поддерживается; критичные цифры не обрезаются.

## Layout & Spacing

Сетка отступов 4/8/12/16/24/32. Экраны приложения — одна колонка, поля 16dp. Главный экран — карта edge-to-edge со статичной нижней панелью: строка статистики, карточка планировщика, CTA.

Эргономика одной руки на ходу — конституционное правило: ключевые действия (старт/стоп, принять задание, «Вытянуть карту») живут в нижней трети экрана, в зоне большого пальца. Верх экрана — только информация и редкие элементы (тогл режима, шестерёнка). Стрелок «назад» в шапках нет — назад через системный жест и явные кнопки-выходы внизу.

## Elevation & Depth

Глубина тональная, а не теневая: поверхности отличаются ступенью сливового. Тени — только у парящих элементов над картой (панель, маркер «я») как физическая метафора «над землёй». Свечение — исключительная привилегия акцентных точек (POI-маяки, индикатор записи, маркер пользователя).

## Shapes

Карточки и кнопки — `{rounded.md}`…`{rounded.lg}`; чипы, тоглы, мини-кнопки — `{rounded.full}` (пилюли); панель — `{rounded.xl}` сверху. Прямоугольность нуля допустима только у карты (весь экран). Эмодзи в макетах — плейсхолдеры: в продукте векторные иконки с подписями; шестерёнка настроек рисуется вектором (эмодзи ⚙ читался как метка локации).

## Components

Визуальные компоновки (все экраны — тёмная и светлая тема рядом для сравнения): `mockups/map-duo.html` (карта, прогулка, финал), `mockups/progress-tasks-duo.html` (прогресс, достижения, задания), `mockups/remaining-screens.html` (POI, рейтинг, регионы, профиль, настройки), `mockups/onboarding-duo.html` (онбординг). При конфликте эта спина важнее макетов.

- **Карта с туманом** — главная поверхность. Слои: база карты → раскрытые просветы → fog-layer → трек (мягкая извилистая линия акцентом, повторяет путь) → POI-маяки → маркер «я» (белое ядро, кольцо `{colors.cursor-dark}`).
- **button-primary** — единственный акцентный залив на экране; нижняя треть; высота ≥48dp.
- **toggle-mode** — два значка без текста, активная сторона — значок на белом кружке с кольцом акцента; при смене — микро-анимация всадника с подписью режима (повторное обучение правилу скорости).
- **sheet (главный экран)** — статичная нижняя панель: статистика мини-колонками без разделителей, карточка планировщика, CTA; не выдвигается, ручки-grab нет.
- **poi-card** — тап по маяку: карточка в нижней зоне поверх карты, название + короткое описание; закрывается тапом вне или свайпом вниз.
- **card-task (активное задание)** — card-active + метка «Активное задание»; действия «Выполнено» / «Отказаться».
- **quest-card (случайное задание)** — крупная карта с описанием; появляется анимацией «раздачи» (~350мс, подброс снизу), замещая кнопку «Вытянуть карту».
- **ach-item** — значок, название, условие; закрытые — пунктирная рамка, приглушённые; почти полученные — полоска прогресса.
- **leaderboard-row** — ранг, ник, значение метрики; текущий пользователь подсвечен card-active.
- **bottom-nav** — 4 вкладки: Карта, Прогресс, Рейтинг, Профиль; иконка + подпись, активная акцентом.

## Do's and Don'ts

| Do | Don't |
|---|---|
| Одна акцентная заливка на экран | Несколько фисташковых кнопок рядом |
| Nunito 1000 для герой-цифр | display-шрифт для обычного текста |
| Rubik Bubbles только на редких праздниках | Bubbles в ежедневных экранах, уведомлениях, кнопках |
| Лавандовый туман как бренд-элемент | Тёмно-серый «военный» туман |
| Векторные иконки с подписями | Эмодзи как иконки интерфейса |
| Значок на белом кружке поверх акцента | Тёмный эмодзи на зелёной заливке (сливается) |
| Мини-колонки статистики: значение над подписью, воздух | Плашки-подложки под подписями, разделители-«таблица» |
| Светлая CTA — призрак: белая заливка, рамка и текст #587110 | Залитая зелёная кнопка в светлой теме |
| Панель главного экрана статична | Выдвижная панель, дублирующая вкладки |
| Заголовки светлой темы в сливовом #4A3F66 | Почти-чёрный текст заголовков на белом |
| Действия в нижней трети экрана | Важные кнопки вверху, стрелки «назад» |
| Акцент текстом в светлой теме — только #587110 | Акцент #7A9A1F как цвет текста (2.96:1 — провал) |
| Частое действие («Пауза») — крупная акцентная кнопка | «Пауза» и «Завершить» одинакового размера рядом |
| Обрыв сессии («Завершить») — призрак с подтверждением | Завершение прогулки одним случайным тапом |
| Компактная иконка с hit-area ≥48dp | Тапабельная область по размеру глифа |
| Тёмная тема как первоклассная | Тёмная тема как инверсия светлой |
