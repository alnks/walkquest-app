# Accessibility Review — WalkQuest (UX spines)

## Verdict: adequate

Поведенческий фloor прописан хорошо (TalkBack, 48dp, Reduce Motion, управление без чтения экрана). Основной риск — контрасты светлой темы и «немые» визуальные события без текстового дублирования.

## Findings

- **[high]** Светлая тема: `ink-dim` `#7A6F8D` на `surface-base` `#F6F3FA` ≈ 3.9:1 — ниже 4.5:1 для мелкого текста (DESIGN.md frontmatter). *Fix:* затемнить light dim до `#6E6384` (~4.6:1) или использовать только для крупного текста.
- **[medium]** Туман/просветы карты: различие «открыто/закрыто» только визуальное. В State Patterns есть текстовое описание прогресса, но не сказано про TalkBack-анонс изменения при растуманивании (EXPERIENCE.md §Accessibility Floor). *Fix:* строка: при открытии новых тайлов TalkBack анонсирует итог прогулки, не каждый тайл.
- **[medium]** Индикатор «Идёт запись» — цвет + точка; для TalkBack нужен текстовый статус в уведомлении трекинга (есть постоянное уведомление — дописать, что оно несёт текст состояния: время/км) (EXPERIENCE.md §Component Patterns). *Fix:* дописать в строку автопаузы/трекинга.
- **[low]** Reduce Motion покрывает всадника и раздачу; добавить «туман расступается без анимации — мгновенно» (EXPERIENCE.md §Accessibility Floor). *Fix:* одна строка.
- **[low]** Эмодзи-значки тогла режима (🚶/🚲) — без текстовых меток; правило «векторные иконки с подписями» в DESIGN.md есть, но для тогла подпись появляется только в анимации. *Fix:* у тогла contentDescription «Режим: пешком / вело» (EXPERIENCE.md §Accessibility Floor).

## Passed

- Тач-зоны 48dp и зазоры 8px зафиксированы.
- Контрастная рамка 4.5:1 заявлена; тёмный dim (#8D83A6) проходит.
- Управление прогулкой без чтения экрана; уведомления — усиление, не несущая конструкция.
- Динамический шрифт без обрезки герой-цифр.
