- (decision) Working mode: coaching path with creative tools
- (decision) Target device: Samsung Galaxy S26 (base model); author prefers dark theme, system-driven (battery saver forces dark) - dark theme is the primary design surface, themes follow system
- (decision) Feedback: first 5 palettes felt generic/AI-standard; user wants stronger, less common visual identity
- (decision) v1 default palette: 7 Lavender Mist (fog is brand element); design system on semantic tokens from day one so palettes are cheap to add later
- (decision) v2 feature 'Seasonal themes': auto-rotation by season + manual pick + 'always this one'; spring=Lavender, summer=White Nights (new, SPb-inspired twilight), autumn=Terracotta&Pine (9), winter=Petrol&Brick (10)
- (decision) Main screen: hybrid - full-bleed map + semi-transparent mini-sheet at bottom, pull-up to expand to stats panel; standard map-app pattern
- (decision) UI terminology: tab is 'Достижения' in product; 'ачивки' is internal working term only
- (decision) Main screen v2 approved: hybrid full-bleed map + sheet (stats chips, planner card, CTA), gear top-right, tabs Карта/Прогресс/Рейтинг/Профиль; Прогресс = статистика + Достижения + Задания; challenges UI name = 'Задания'
- (decision) Typography: Nunito 1000 (R1) = main display font for digits/headers; Rubik Bubbles (R5) reserved for rare celebratory moments only (achievement unlock, district complete) - 'fog-like' but dosed; body text neutral (Manrope/system)
- (decision) Walk screen: map dominant (~65%), stats small + neutral font; mode = toggle (day/night style) placed top-left of MAIN screen (chosen before start, not during); track renders as soft curved polyline following actual path
- (decision) Final screen privacy: NO district/location name (shareable screenshot safe); distance/time/streak in neutral font; playful display font only for ONE hero number; hero number choice (% region vs other) under consideration
- (decision) Mode toggle: icons only (pedestrian/bike), top-left; on switch, micro-animation rides across topbar with label ('Режим велопрогулки'/'Режим пешей прогулки') - wow moment that also re-teaches mode rule; fallback if heavy: static icons toggle
- (decision) Final screen: playful font ONLY for hero % number (Nunito 1000 identity anchor); title 'Отличная прогулка!' neutral Nunito 800; Rubik Bubbles reserved for rare celebrations (district complete, milestone); main screen chips: открыто % / серия / цель
- (decision) Onboarding v2: no skip button (screen 1 is the only teaching screen, rest is mandatory setup); scr1 text 'велосипеде или самокате, на другом транспорте не засчитывается' (no 'честные ноги'); scr2 title 'Где вы живёте?'; scr2 second sentence: при смене региона подгрузится нужная карта, прогулки продолжатся (region includes towns); scr3: pick metric type then adjust value, note it's changeable in settings; scr4 title 'Доступ к геолокации', plain language 'информация о ваших передвижениях не покидает телефон', no Later button
- (decision) Progress tab: 3 segmented sections; Статистика = hero % + stat tiles (walks total, km total, current streak, achievements count, tasks done) + list for number-lovers (max streak, avg km/day, avg walk time, regions visited); Достижения = unlocked + locked WITH unlock conditions shown, near-done get progress bars; Задания = random card or pick 1 of 6, accept/decline buttons, completion mark, active task pinned on top
- (decision) Achievements tab: split into collapsible Полученные/Неполученные sections with tap-to-scroll; full achievement catalog to be designed in a separate content session after UX finalize, before tickets; Задания tab gets mini-instruction (optional feature framing) + decline/mark-skipped for taken tasks; light theme mocks for all key screens at Finalize
- (decision) ui-ux-pro-max validation pass: font system Nunito 1000 hero digits + DM Sans body (Cyrillic, DB-backed pairing 'Claymorphism Mobile') + Rubik Bubbles rare celebrations; touch targets >=48dp with >=8px gaps; dimmest label color raised #7d7194 -> #8d83a6 for 4.5:1 contrast; emoji in mocks are placeholders, app uses vector icons with labels
- (decision) Задания tab: note text 'Задания помогут разнообразить вашу прогулку. Их выполнение необязательно :)'; one active task at a time (attention on walk is scarce; new task only after done/declined); action buttons solid + centered icon/label; 'Выполненные' header; random task = quick card-deal flip-in animation ~350ms; pick-6 cards get 1-2 sentence descriptions; full task catalog designed in content session with achievements after UX finalize
- (decision) Navigation: NO back arrows in header (unreachable while walking); back = Android edge-swipe gesture (must work app-wide, predictive back) + 'Не сейчас' escape button; random-task: 'Вытянуть карту' button centered, on deal the button is REPLACED by the card in place, actions on the card
- (decision) Ergonomics: key action buttons live in the lower thumb zone (bottom third of screen), not geometric center - one-handed use while walking
- (decision) Light theme feedback: toggle active icon needs contrast (pedestrian legs blend on green) - icon on white circle with accent ring; gear emoji replaced by drawn SVG gear (looked like location pin); statline becomes 3 mini-columns (value over label, hairline dividers); final screen headings softened from near-black to plum #4A3F66; light theme to be rendered for EVERY screen
- (decision) POI card: photo strip 2-3 images from Wikimedia/Wikipedia (open licenses) in v1; category label dropped (all POIs are interesting places); longer description text.
