# Контент-каталог v1: Достижения и Задания

Рабочий документ контентной сессии. Правила из спин: голос — короткие человеческие фразы на «вы», без стыда и канцелярита; Rubik Bubbles — только редкий триумф. У каждого неполученного достижения видно условие; у близких — полоска прогресса. Одно активное задание за раз; выполнение — на честном слове; отказ без штрафа («Задание снято»).

## Модель территории (важно для достижений)

- **Город** — населённый пункт пользователя (СПб, Гатчина, Колпино…). Процентные достижения считаются по городу.
- **Регион (область)** — субъект: Ленобласть, Московская область и т.д. Для городов федерального значения (СПб, Москва) город и регион совпадают.
- **Пригород** — прогулки в других населённых пунктах своей области.
- **Районы** — только в городах с административным делением (в СПб: Адмиралтейский, Приморский, Фрунзенский…). В малых городах районные достижения скрываются.
- Краевой случай разрешён так: Гатчина — отдельный город в Ленобласти, а не часть СПб; житель Гатчины получает город = Гатчина, область = Ленобласть.

## Открытые вопросы контента

- Региональные достижения (специфика города) — v2, когда появится второй регион у аудитории.
- Сезонные задания (снег, листопад) — вместе с сезонными палитрами v2.
- Пороги километров за пределами сотни (200/500 км) — добавить при появлении первых «сотников».
- Баланс пула заданий: следить за долей «сезонных» (вода, мост) для городов без воды — при запуске собрать статистику отказов и докрутить веса.
