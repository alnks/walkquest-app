# Спецификация экранов WalkQuest

Каждый экран описан словами: расположение элементов по третям экрана, сетка
отступов (токены `WqTheme.spacing`: xs 4 / sm 8 / md 12 / lg 16 / xl 24 /
xxl 32, поля экрана 16dp), компоненты Шага 2 (`ui/components`), состояния
(default / loading / empty / ошибка) и копии. Навигация утверждена: 4 вкладки
(Карта · Прогресс · Рейтинг · Профиль), модальных стеков глубже одного нет,
стрелок «назад» нет — выход явными кнопками внизу или системным жестом.

Общие правила всех экранов:
- Тёмная тема — первоклассная, светлая — полноценная вторая; обе следуют
  системной настройке.
- Верх экрана — только информация и редкие элементы (тогл режима, шестерёнка);
  ключевые действия — в нижней трети, в зоне большого пальца.
- Тексты: заголовки — `headingScreen/headingSection/headingCard` (Nunito 800),
  тело — `body/bodySmall` (Manrope, замена DM Sans — см. WqTypography.kt),
  подписи — `meta` (12sp, минимальный кегль). Никаких hex и MaterialTheme
  напрямую — только `WqTheme.colors` / `WqTheme.typography`.
- Одна акцентная заливка (WqPrimaryButton) на экран.

## 1. Главная карта (вкладка «Карта», не запись)

**Каркас:** карта edge-to-edge (весь экран, прямоугольность нуля допустима
только у карты). Поверх — слои из верхней зоны; внизу — статичная панель.

**Верхняя треть:**
- Левый верхний угол — `WqModeToggle` (режим пешком/вело, значки без текста,
  белый кружок-«всадник» с кольцом акцента). Отступ: поля lg (16dp) от краёв
  + `statusBarsPadding()`.
- Правый верхний угол — `WqIconFab` со шестерёнкой («Настройки», 48dp hit-area).
- По центру сверху — `RegionProgressBadge`: пилюля surface-raised с парой
  «17,4% / открыто» — реализовано как `WqStatColumn` внутри pill-Surface
  (тональная глубина, тень 4dp, над картой). Скрывается, если прогресс ещё
  не считается (регион не установлен).
- Условные плашки-чипы (`WqChip`): «Определяю местоположение…» (нет свежего
  фикса, точка отсутствует), «Вы вне области пакета — прогулка не
  засчитывается» (запись вне покрытия), карточка предложения региона.

**Средняя треть:** чистая карта (туман, POI-маяки, маркер «я»). Ничего
дополнительного — приложение не требует постоянного внимания.

**Нижняя треть:** `WqSheet` — статичная панель (скругление сверху 20, фон
surface-base, тень 8dp, перекрывает карту на ~20px; углы прозрачны до карты):
1. Строка статистики: три `WqStatColumn` (`SpaceEvenly`): «открыто» / «серия»
   (n дней) / «за неделю» (км). Значения акцентом Nunito 800, подписи meta
   ink-dim, без разделителей и подложек. Пока данных нет — прочерк «—».
2. Карточка планировщика: `WqCard` (или WqCard без тапа) с текстом ближайшего
   плана «Завтра, 12:00 — прогулка по плану»; справа иконка-кнопка «+»
   (`WqIconFab`-стиль текст-кнопка) открывает диалог даты/времени. Пустое
   состояние: «Нет планов — нажмите +, чтобы запланировать прогулку» (ink-dim).
3. CTA `WqPrimaryButton` «Начать прогулку» — единственная акцентная заливка
   экрана, во всю ширину панели.

**Справа внизу** (над панелью): `WqIconFab` «к моей точке»; без фикса позиции —
приглушена (ink-dim) и неактивна.

**Состояния:**
- default: карта с туманом, панель статистики, CTA.
- loading установки региона: карточка предложения с кнопкой «Загружается…»
  (disabled) и точкой-индикатором.
- empty (регион не установлен): карточка «Загрузите домашний регион» + CTA
  «Загрузить»; статистика скрыта.
- ошибка установки: типизированное сообщение domain внутри карточки
  предложения цветом error.
- нет разрешения на геолокацию: карта работает, маркера нет; при старте —
  честное объяснение и запрос разрешения.

**Копии:** «Начать прогулку», «открыто», «серия», «за неделю»,
«Нет планов — нажмите +, чтобы запланировать прогулку», «Определяю
местоположение…», «Вы вне области пакета — прогулка не засчитывается».

## 2. Прогулка (запись идёт / на паузе)

**Каркас:** карта максимальна; панель — `WqSheet` внизу (та же статичная
механика). Тогла режима на экране прогулки нет (режим выбирается до старта).

**Верхняя зона:** `WqChip` состояния записи: «Идёт запись» (точка акцентом) /
«На паузе» (точка ink-dim, без свечения). Плюс, при необходимости, чип
«Определяю местоположение…» и плашка «вне области пакета».

**Средняя зона:** карта + трек. Нейтральная строка агрегатов живёт в панели,
а не поверх карты — экран читается одним взглядом.

**Нижняя треть — `WqSheet` (панель прогулки):**
1. Три `WqStatColumn`: «время» (мм:ss / ч:мм) / «км» (0,0) / «клеток открыто».
2. Ряд кнопок: `WqPrimaryButton` «Пауза» (или «Продолжить») — крупная
   акцентная, частое действие; `WqGhostButton` «Завершить» — обрыв сессии,
   только с подтверждением (AlertDialog «Завершить прогулку?» / «Прогулка
   будет сохранена в историю.» / «Завершить» / «Продолжить прогулку»).
   Don't: одинаковые кнопки рядом.

**Над панелью:**
- `WqIconFab` «+ Задание» (плюс, тон акцент) — если включено в настройках;
  открывает поток заданий поверх прогулки (запись не останавливается).
- Карточка активного задания `WqQuestCard(active = true)` с действиями
  «Выполнено» / «Снять» (TextButton акцентом/ink-secondary).
- FAB «к моей точке» — как на главной.

**Состояния:** запись / пауза (чип и подпись кнопки меняются); GPS-сбой —
точки молча отсекаются лимитом скорости (правило знает пользователь из
обучения); батарея 15% — предупреждение, 10% — автозавершение с финальным
экраном; потеря процесса — запись восстанавливается без потери трека.

**Копии:** «Идёт запись», «На паузе», «Пауза», «Продолжить», «Завершить»,
«Завершить прогулку?», «Продолжить прогулку», «+ Задание» (TalkBack:
«Задание на прогулку»).

## 3. Финал прогулки (оверлей поверх всего)

**Каркас:** полноэкранная Surface surface-raised, весь контент по центру,
без прокрутки (никаких подписей-постскриптумов). Отступы xl (24dp) + системные
инсеты.

**Состав (сверху вниз):**
1. Похвала — `headingSection` (Nunito 800): «Отличная прогулка!» (из domain,
   без названия района — скриншот безопасен для шеринга). Игривая только
   герой-цифра; праздничный Rubik Bubbles здесь не используется (ежедневный
   экран).
2. Отступ xl.
3. Герой-цифра: `displaySmall` (Nunito 1000, 38sp) акцентом — «17,4%»; под
   ней подпись body «территории открыто» ink-secondary. Если прогресс не
   считался — блок скрыт.
4. Строка-итог `headingCard`-подобная: «12,3 км · 45 мин».
5. Новые достижения (если есть): строки body с иконкой; на юбилейной метрике
   допустим `celebration`-стиль (редкий праздник).
6. Отступ xxl, подпись про завтра body ink-secondary (TOMORROW_NOTE).
7. `WqPrimaryButton` «Поделиться результатом»; ниже текст-кнопка «Закрыть»
   (ink-secondary) — выход внизу, стрелки нет.

**Состояния:** единственное (сводка приходит готовой из viewmodel); achievements
может быть пусто — блок скрывается. Автозавершение по батарее — то же самое.

**Копии:** «Отличная прогулка!», «территории открыто», «Поделиться»,
«Закрыть» + TOMORROW_NOTE из domain.

## 4. Онбординг (4 шага, первый запуск)

**Каркас:** полноэкранный оверлей surface (скрывает нижнюю навигацию), контент
в одну колонку с полями xl (24dp), `SpaceBetween`: верхний ряд / контент по
центру / нижний ряд. Без кнопки «пропустить» на экране цели (обучение +
обязательная настройка).

**Шаги 1–3 (обучение):** заголовок `headingSection` по центру, тело `body`
по центру. Темы: «Город под туманом» (карта скрыта завесой, расступается от
прогулок; транспорт не засчитывается), «Туман расступается от прогулок»
(только реальное перемещение), «Честный подсчёт» (лимиты скорости пешком/вело).
Нижний ряд: `WqPrimaryButton` «Дальше» / «Дальше: цель». Верхний ряд справа:
текст-кнопка «Пропустить» (ink-secondary) — прыгает сразу к цели.

**Шаг 4 (цель):** заголовок «Ваша цель». Три сегмента-выбора типа цели —
`WqSegmentPill` (высокие ≥48dp): «Прогулки в неделю» / «Минут в день» /
«Км в день». Степпер: «−» / значение (headingCard, «3 прогулки в неделю») /
«+». CTA `WqPrimaryButton` «Начнём».

**Состояния:** default только; цель обязательна (FR-11), кнопка активна
всегда (значения ограничены диапазоном).

**Копии:** см. OnboardingOverlay (утверждены прототипом ob1–ob4, менять нельзя).

## 5. Прогресс (вкладка, 3 сегмента)

**Каркас:** фон surface-base, `statusBarsPadding`, заголовок экрана
`headingScreen` «Прогресс» (поля lg). Под ним — сегмент-контрол: три
`WqSegmentPill` в ряд с зазором sm, каждая `weight(1f)`, высота ≥48dp, шрифт
metaLarge 13sp. Каждый вход во вкладку открывает «Статистику» (выбор не
запоминается).

### 5a. Статистика (сегмент 0)
Колонка с полями lg, зазоры xl между блоками:
- «Цель: …» body ink-secondary (если задана).
- loading: `LinearProgressIndicator` (токен accent) вместо данных.
- Три строки «Серия / Прогулок / Расстояние»: label body ink-primary слева,
  значение body акцентом Nunito... — спецификация stat-line для ПРОСТЫХ
  строк: label body, значение `headingCard` (Nunito 800) справа
  (`SpaceBetween`), без разделителей.
- «Регионы» (`headingSection`): строка названия + процент `headingCard`
  акцентом; под ней `LinearProgressIndicator` 6dp высотой (track ink-dim
  приглушённо).
- «Планы» (`headingSection`) + текст-кнопка «Запланировать»: строки планов
  «дд.мм.гггг чч:мм — статус» (✓ выполнен / пропущен (без наказания) /
  ожидает), справа «Отмена» для будущих. Пусто — ничего (кнопка создания есть).

### 5b. Достижения (сегмент 1)
Секции по категориям: подзаголовок категории `headingCard`; строки достижений:
иконка (24–32dp), название body (+звезда «✦» акцентом у rare), подпись:
«Получено дд.мм.гггг» или условие получения — meta ink-dim; у близких —
`LinearProgressIndicator` 4dp с отступом от иконки. Неполученные приглушены
(ink-secondary/dim). Сворачиваемость секций — отложено (deferred-work).

### 5c. Задания (сегмент 2)
См. §6 — тот же поток без кнопки закрытия.

**Состояния:** пустая история — «Здесь появятся ваши прогулки — начните с
карты» + ссылка на Карту (для будущих версий статистики); у достижений и
заданий пустые секции скрываются/показывают короткую пустую подпись.

## 6. Задания (сегмент «Задания» и оверлей «+ Задание»)

**Каркас:** колонка с полями lg, зазоры md; заголовок `headingScreen` «Задания»
(на оверлее прогулки — кнопка «Готово» акцентом справа, возвращает на экран
прогулки, а не во вкладку).

**Поток:**
- Инструкция: «Задания помогут разнообразить вашу прогулку. Их выполнение
  необязательно :)» body ink-secondary.
- Нет активного: CTA `WqPrimaryButton` «Вытянуть карту» (нижняя зона пальца) и
  `WqGhostButton` «Выбрать из 6».
- «Вытянуть карту» → раздача (~350мс, подброс снизу) → `WqQuestCard`
  (active = false, крупная) с действиями «Ещё раз» (пересдача) и
  «Принять задание» (акцентная CTA прибита к нижней зоне), под ней «Не сейчас»
  — выход.
- Активное: `WqQuestCard(active = true)` с меткой «Активное задание» и
  действиями «Выполнено» / «Отказаться» (+«Другое» в сегменте). Одно активное
  за раз; новое не берётся, пока текущее не закрыто (диалог подтверждения
  замены: «У вас уже есть задание» / «Прежнее задание снимется без штрафа.» /
  «Взять новое» / «Оставить текущее»).
- «Выбрать из 6»: подзаголовок «Выберите задание» (`headingSection`) и сетка
  карточек `WqCard` (иконка+название+описание), тап — принятие; «Отмена».
- История: подзаголовок «Выполненные · N» (meta ink-dim); строки «иконка
  название» ink-secondary + «✓» акцентом. Пусто — «Пока нет выполненных
  заданий.»

**Состояния:** кнопка заданий выключена в настройках — объяснение + кнопка
«Включить» (акцентом).

## 7. Рейтинг (вкладка)

**Каркас:** колонка, поля xl (24dp), зазоры md; заголовок `headingScreen`
«Рейтинг». Участие опционально, агрегаты только (AD-3).

**Первый вход (ник не задан):** подпись «Придумайте ник — так вас увидят
другие» body; поле ника (OutlinedTextField на токенах M3-инфраструктуры);
ошибка валидации — текст error; `WqPrimaryButton` «Вступить в рейтинг»;
ниже текст-кнопка «Остаться невидимым» (ink-secondary).

**Основной экран:**
- Строка «Вы: ник» (+ «(невидимый режим)»).
- Сегменты «Город» / «Друзья» — `WqSegmentPill` (≥48dp, 13sp) + текст-кнопка
  «Обновить».
- Лидерборд: строки «ранг. ник» слева, метрика «км · %» справа; текущий
  пользователь — строка в `WqCardActive` (подсветка), скрытый из рейтингов —
  без ранга, с подписью «вы скрыты; включите участие в настройках».
- «Друзья» пусто — «Пока здесь только вы. Пригласите друга по ссылке» +
  кнопка шеринга. Код приглашения: «Код приглашения: X — отправьте другу» +
  «Пригласить друга»; поле ввода чужого кода + «Принять приглашение».

**Состояния:** loading — индикатор/скелетон простой; пусто — приглашение;
офлайн — последний кеш + пометка «данные на [время]», без баннеров; ник не
задан — форма выше; ошибка сети — notice с кнопкой «Понятно».

## 8. Профиль (вкладка)

**Каркас:** фон surface-base; заголовок `headingScreen` «Профиль» (поля lg).
Колонка карточек `WqCard` с вертикальными полями 6dp (межкарточный ритм) и
внутренними отступами md.

**Состав:**
1. Шапка: `WqCard` — ник (`headingCard`; «Ник не задан», если null), статус
   участия meta ink-dim («задаётся при первом открытии Рейтинга» / «в рейтинге ·
   участие вкл/выкл»), «Моя цель: …» bodySmall ink-secondary.
2. «Мои регионы» — `WqCard` с onClick: подпись body ink-secondary + стрелка
   «→» акцентом (переход на экран регионов).
3. Предупреждение `WqCard`: «Данные живут только на этом устройстве: удаление
   приложения без экспорта безвозвратно удалит весь прогресс.» — постоянно
   (Done when 2), body ink-secondary.
4. «Перенос прогресса» `WqCard`: заголовок `headingCard` + подпись meta +
   кнопки «Экспорт» / «Импорт» (текст-кнопки акцентом; «Сохранение…» при
   экспорте). Импорт — диалог подтверждения: «Импортировать копию?» / «Текущие
   данные будут заменены копией от …» / «Заменить» / «Отмена».
5. Недостающие регионы копии (если есть) `WqCard`: строки regionId + кнопка
   «Скачать» («Скачивание…» во время загрузки).
6. Сообщения/ошибки — строки bodySmall акцентом/error под карточками.
7. «О приложении»: подзаголовок meta ink-dim; `WqCard`: строка «Версия» +
   значение meta; строка «Политика конфиденциальности» + «→» (открывает
   браузер).

**Состояния:** default; busy-флаги (exportBusy, downloadingRegionId) — подписи
кнопок меняются, повторные тапы заблокированы.

## 9. Мои регионы (экран первого уровня из Профиля)

**Каркас:** фон surface-base, `statusBarsPadding`; заголовок `headingScreen`
«Регионы». Список (LazyColumn) с полями lg и зазорами sm между строками; внизу
списка — `WqGhostButton` «Готово» (явный выход; стрелок нет).

**Строка региона — `WqCard` с onClick:** процент (`headingCard`): домашний —
акцентом (accentText), чужие — ink-secondary (приглушённый лавандовый);
название body bold (Nunito... специфика: название `headingCard`? — нет, по
макету название строки среднее: body + Bold недоступен в Nunito-800-роли;
используем `headingCard` 16sp Nunito 800) и подпись meta: «домашний регион» /
«установлен». Действия строкой: «Обновить» (если есть версия выше; «Обновляется…»
во время установки, блокирует прочие обновления) и «Домашний» (сделать
домашним, ink-secondary) для не-домашних.

**Состояния:** empty — «Пока нет установленных регионов. Загрузите домашний
регион — карточка на вкладке «Карта».»; ошибка — строка error под заголовком;
загрузка региона — прогресс на карточке предложения на Карте (трекинг не
прерывается).

## 10. Настройки (оверлей с шестерёнки главного экрана)

**Каркас:** фон surface-base, `statusBarsPadding`; заголовок `headingScreen`
«Настройки». Скроллящаяся колонка, поля lg, зазоры md. Выход — явная кнопка
«Готово» внизу (`WqPrimaryButton` во всю ширину); стрелок нет. Два входа
(шестерёнка + пункт в Профиле) — намеренно (EXPERIENCE).

**Состав:**
- Подзаголовок секции meta ink-dim: «ПРОГУЛКА».
- `WqCard`: строка «Режим по умолчанию» + два `WqSegmentPill`-подобных
  выбора «Пешком» / «Вело» (выбранный — акцентная заливка, невыбранный — текст
  ink-secondary); далее три `SwitchRow`: «Автопауза при остановке» («Прогулка
  сама встанет на паузу после 15 минут неподвижности»), «Напоминание о
  забытой прогулке», «Кнопка «Задания» на прогулке». Свитчи: включённый трек —
  акцент, ползунок белый; подписи title body ink-secondary, subtitle bodySmall
  ink-dim.
- Подпись-успокоение bodySmall ink-dim: «Настройки применяются ко всем
  прогулкам и хранятся на устройстве.»
- `WqPrimaryButton` «Готово».

**Состояния:** default; переключатели меняют состояние мгновенно (UDF).

## 11. POI-карточка (поверх карты, нижняя зона)

**Каркас:** `WqCard` с увеличенным радиусом lg (16dp) — токен large; поверх
карты, над прототипными кнопками записи; поля lg по бокам; закрывается кнопкой
«Закрыть», свайпом вниз или тапом вне карточки (карта обрабатывает tap-outside).

**Состав:**
- Фото (если есть в пакете): полоса во всю ширину сверху (~96dp, crop), при
  загрузке — плейсхолдер surface-sunken, битый файл — без полосы.
- Заголовок: `headingSection` (Nunito 800) название, справа текст-кнопка
  «Закрыть» ink-secondary.
- Описание: body ink-secondary, максимум 4 строки с многоточием; если обрезано
  и есть url — ссылка «Подробнее» акцентом с подчёркиванием (открывает браузер).
- Нет описания — категория места строкой meta ink-dim.

**Состояния:** описание null — категория; фото отсутствует/битое — текстовая
карточка; в тумане маяк не кликабелен (тап — подсказка «дойдите до точки» —
чип-подсказка); растуманенная непрочитанная точка пульсирует (маяк), после
прочтения — кольцо (можно перечитать).

**Копии:** «Закрыть», «Подробнее».

## Отложено (не входит в миграцию, deferred-work)

- Полный экранный редизайн Рейтинга/Статистики под мокапы (вкладки,
  состояния) — текущая миграция меняет только токены/компоненты, не
  бизнес-логику и не структуру.
- «Всадник» режима 2.4с с подписью режима (EXPERIENCE) — сейчас короткая
  пружина кружка; длинная обучающая анимация — отдельной задачей.
- Reduce Motion: системный флаг не читается (анимации короткие, кроме
  всадника).
- Секции достижений сворачиваемые; стрики без стыда — как в PRD.
