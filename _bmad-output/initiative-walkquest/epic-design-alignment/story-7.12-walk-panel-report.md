# Сторя 7.12 — панель прогулки (запись/пауза)

Источники истины: `mockups/map-duo.html` (секции «Прогулка», «Пауза»),
`EXPERIENCE.md` (экран прогулки — завершение УДЕРЖАНИЕМ ~600 мс, спина важнее),
`screens-spec.md` §2, `DESIGN.md` (токены), расхождения — `compare/README.md`
(02-map-walk, 02п-map-walk-paused, «Осталось» №6).

## Правки

1. **Третья метрика — прирост процента.** Вместо «клеток открыто» панель показывает
   «+0,4% открыто» (макет): `MapViewModel` на старте записи снимает
   `walkStartFraction` (доля открытия активного региона) и по мере открытий
   тайлов считает дельту → `MapUiState.walkGainFraction`; на панели —
   `WqFormat.walkGain` (знак «+», ru-запятая, честное «+<0,1%» на первых
   тайлах, «—» если прогресс не считается, отрицательный прирост зажат в ноль —
   открытия необратимы).
2. **Общий хелпер форматирования `WqFormat`** (`ui/common/WqFormat.kt`, чистый
   JVM): `km()` и `percent()`/`walkGain()` с `Locale ru-RU`. Заменены все
   `"% .1f".format(...)` — исправились ОБЕ панели (прогулки «0,1» и домашней
   «0,0 км» за неделю), плюс сетка финала и текст шеринга.
3. **«+ Задание» — пилюля.** Вместо FAB «+» (`QuestFab` удалён) —
   `QuestPillButton`: плюс + «Задание», призрак с пунктирной рамкой
   (`drawBehind` + `PathEffect.dashPathEffect`, токен `borderStrong`), фон
   `surfaceRaised`, текст/иконка `inkSecondary`, hit-area ≥48dp, TalkBack
   «Задание на прогулку» (spec §2). Поведение прежнее: открывает поток заданий
   поверх прогулки (запись не останавливается — проверено на устройстве).
   Активное задание — прежняя карточка `WqQuestCard(active)` над панелью (spec §6).
4. **«Завершить» — удержание ~600 мс.** AlertDialog убран полностью
   (`finishConfirmVisible` и блок диалога удалены; source conflict зафиксирован:
   EXPERIENCE важнее screens-spec §2). Чистая логика — `HoldToConfirmLogic`
   (`ui/common`, THRESHOLD_MS = 600, ROLLBACK_MS = 200, `progress()`,
   `isConfirmed()`); UI — `FinishHoldButton`: `Animatable`-заполнение акцентом
   слева (alpha 0.35 тёмная / 0.28 светлая, как `.btn-stop.holding`) за 600 мс
   линейно; отпускание до порога откатывает заполнение за 200 мс и НЕ завершает;
   порог достигнут → `ACTION_STOP` (кнопка уходит вместе с панелью, откат не
   нужен). Текст подсказок нет — механика читается анимацией (EXPERIENCE);
   TalkBack — contentDescription с описанием жеста. Пилюля-призрак по токенам
   (`borderStrong` 1.5dp, `shapes.full`, `inkSecondary`).
5. **Чип состояния.** `WqChip` получил `textColor` и `dotGlow`: «Идёт запись» —
   текстом акцентом (`accentText`) с точкой акцентом со свечением (DESIGN
   Elevation: свечение — привилегия акцентных точек), «На паузе» — `inkSecondary`
   с dim-точкой без свечения. Кнопка паузы: «Пауза»/«Продолжить» —
   `WqPrimaryButton` с весом 1.7 против 1.0 у «Завершить» (макет `.btn-pause`
   flex 1.7; DESIGN Do: частое действие крупнее).
6. **POI-карточка (7.10) не тронута.** Pre-existing перекрытие углом карточки
   пилюли QuestFab починено тривиально: пилюля скрывается, пока открыта
   карточка POI во время записи (симметрично поведению FAB «к моей точке» в idle).

Все цвета/шейпы/типографика — токены `WqTheme`; новых hex вне `ui/theme` нет.

## Отступления и открытые вопросы

1. **Подпись колонки «км» vs «расстояние».** Макет рисует «расстояние», оставил
   «км» — screens-spec §2 («км») новее и является спецификацией; при
   необходимости однострочная правка в `WalkPanel`.
2. **Тогл режима во время записи.** EXPERIENCE (строка 62) говорит «на экране
   прогулки тогла нет», реализация показывает его (pre-existing, вне скоупа
   7.12) — кандидат на разбор владельцу; на склейках виден.
3. **Значения метрик в склейках** (01:58 / 0,1 км / +0,0%) сценарно малы —
   трек sim-walk-ok ~26 м; формат (запятая, плюс, «+<0,1%») демонстрируется,
   числа зависят от сценария (прецедент зафиксирован в compare/README для
   чистой установки). Длинный трек (fix7-walk, 523 м) через `wq.py replay`
   давал бы «0,5 км», но требует ~4 мин ожидания; `wq.py simulate` неприменим
   при живой записи (сервис игнорирует SIMULATE, если уже пишет).
4. **Зависание шага региона онбординга** («Определяем регион по геолокации…» не
   разрешилось после двух geo fix; «Выбрать другой» не отзывался) — пройдено
   через «Пропустить»; похоже на pre-existing дефект, не связанный с 7.12
   (зависит от тайминга фикса при старте оверлея). Зафиксировано в deferred-work.
5. **Автопауза/батарейный страж** не трогались; `walkGainFraction` считается
   для активного региона, при смене региона середины прогулки дельта по нему же
   (практически не случается; домашний регион фиксирован на запись).
