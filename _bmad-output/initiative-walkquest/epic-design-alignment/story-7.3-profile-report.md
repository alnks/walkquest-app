## Расхождения макет ↔ спека и их разрешение

1. **Предупреждение о локальности данных и «Экспорт»/«Импорт»** — в макете
   отсутствуют, спека §8 (пп. 3–4) требует постоянно → спина важнее
   (правило EXPERIENCE «при конфликте спина важнее макета» и п.6 задания).
   Оба блока сохранены под группой строк; строка «Перенос прогресса»
   (экспорт →) дублирует быстрый доступ к экспорту — осознанно, чтобы строка
   макета оставалась рабочей.
2. **Копия цели**: макет «3 прогулки/нед →» vs domain `describe()`
   «3 прогулки в неделю» → взята domain-строка (AD-4: UI рендерит готовые
   строки, не форматирует; «прогулки/нед» — макетная компактная форма, в спеке
   не утверждена).
3. **Шапка**: спека §8 описывает её как WqCard с «Моя цель: …» — по макету
   шапка без карточки, а цель — строкой группы с пилюлей (задание стори
   формулирует цель как строку группы). Выполнено по макету; копии статуса —
   утверждённые спекой.
4. **Значения на склейках** — честные данные устройства (ник/цель подложены
   через run-as, 1 регион), не макетные «2 →».

   редактор цели появится со стори настроек (11-settings в списке расхождений

   пакетов будет «0 →» — честное состояние, как решено для сверки 08.
