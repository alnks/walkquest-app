## Чек-лист расхождений

### A. Решение владельца (блокируют «чистое» закрытие эпика)

- [ ] **A1 (7.1). Название региона:** реализация «Санкт-Петербург» (имя из манифеста
      пакета) vs макет «Санкт-Петербург и Ленобласть». Переименовать в данных пакета?
      Сторона данных, не экрана.
- [ ] **A2 (7.2). Подпись hero финала:** макет «домашнего региона открыто (+0,4%
      сегодня)» vs утверждённая spec §3 «территории открыто». Оставлено по spec —
      макет кандидат на приведение в соответствие.
- [ ] **A3 (7.2). Кегль hero:** реализация `displaySmall` 38sp (по spec §3 п.3),
      макет визуально ~48sp. Если «крупнее» — однострочная правка на `displayMedium`.
- [ ] **A4 (7.2). Подзаголовок «вечер · 48 минут»** из макета не реализован (в spec
      нет). Нужен? Микро-правка.
- [ ] **A5 (7.4). Source conflict карточек:** макет/AL-4 требуют сетку из 6 карточек
      с подложками, DESIGN.md «Do's and Don'ts» плашки запрещает. Выполнено по AL-4
      (эпик важнее спины для этого экрана) — зафиксировать решение в спине или
      ослабить правило.

### B. Кандидаты на микро-правки / доводку

- [ ] **B1 (7.4/7.5). Спека §5a устарела** — описывает старую структуру статистики
      («Цель/Серия/Прогулок/Расстояние» + «Регионы»), противоречит AL-4. Обновить
      спеку (7.6 или документация).
- [ ] **B2 (7.3). «Моя цель»** ведёт в оверлей Настроек, где группы «Цель» пока нет
      (появится со стори 11-settings). Редактор цели раньше стори 11 — по желанию.
- [ ] **B3 (7.3). Копия цели:** domain «3 прогулки в неделю» vs макетная компактная
      «3 прогулки/нед». Взята domain-строка (AD-4). Утвердить форму.
- [ ] **B4 (7.5). Порог прогресс-бара** — полоска при нормированном прогрессе ≥ 1%
      цели (суб-пороговый «<0,1%» не рисуется). Однострочная константа; строгое `>0`
      — по решению родителя.
- [ ] **B5 (7.5). Эмодзи-значки достижений** — плейсхолдер по DESIGN. Полный набор
      векторных иконок — отдельная дизайн-задача вне 7.5.

### C. Известные ограничения / вне скоупа (не дефекты вёрстки)

- [ ] **C1 (7.1). Офлайн-онбординг, шаг 2:** live-предложение региона не резолвится
      без сети, «Выбрать другой» при пустых options не раскрывает пикер, CTA
      выключена; выход — «Пропустить». Отдельной копии состояния в макете нет.
- [ ] **C2 (7.1/7.4). Кегли по потолку шкалы DESIGN:** заголовки онбординга 24sp при
      пропорциональных ~27sp макета; подписи 7.4/7.5 — токенами `meta` 12sp /
      `headingCard` 16sp вместо макетных 9–11px (прецедент спины: мин. кегль 12px).
- [ ] **C3 (7.4/7.5). Не проверено на устройстве состояние «с данными»** статистики
      (агрегаты покрыты JVM-тестами; форматирование ru-локалью тождественно 7.2).
- [ ] **C4 (7.5). Полный скролл 38 карточек** не снимался; `verticalScroll` вместо
      LazyColumn — сознательно (список короткий и статичный).
- [ ] **C5 (все). Честные данные vs макетные наполненные состояния** — согласованное
      расхождение состояния (прецедент экрана 01), вёрстка не пострадала.
- [ ] **C6 (7.1). Численный pixel-diff для онбординга не строился** — сверка визуальная
      по склейкам, порогов не на чем сверять.
