## 2. Открытые решения (10, с обоснованием — см. compare/README.md)

1. **FAB «К моей точке»** — макет vs spec §1; реализация по спеке, воля владельца финальна.
2. **Иконки нижней навигации** — спина молчит о форме; глифы ◈◎▦◉ макета vs семантические векторы; вопрос владельцу.
3. **Ручной выбор темы** — пилюля «системная» без действия; EXPERIENCE/DESIGN/spec §10 выбор не предусматривают.
4. **Эмодзи-значки достижений/заданий** — плейсхолдеры по DESIGN; полный набор векторов — отдельная дизайн-задача.
5. **Даты в истории заданий** — QuestStateStore хранит только doneIds; расширение store — отдельная задача.
6. **Онбординг офлайн без манифеста** — шаг региона висит, выход «Пропустить»; отдельного состояния в макете нет.
7. **«Автозавершение при разряде»** — в макете есть, в коде нет, спина спорна; решение владельца.
8. **Живая проверка рейтинга** — HITL владельца после восстановления Supabase (контракт подтверждён mock-сервером).
9. **Поправка spec §1 про RegionProgressBadge** — спина устарела после AL-11; владельцу обновить screens-spec.md.
10. **Жёлтый штрихованный круг на карте во время записи** — триаж из sweep 7.13: артефакт MapLibre или маркер цели
    без задания; подтвердить на свежей сборке, при повторении расследовать слой карты.
