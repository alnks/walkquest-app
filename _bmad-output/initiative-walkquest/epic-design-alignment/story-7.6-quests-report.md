Сегмент «Задания» вкладки «Прогресс» (и оверлей «+ Задание» поверх прогулки,
тот же `QuestsContent`) приведён к утверждённому макету
`mockups/progress-tasks-duo.html` (секция «Прогресс · Задания») согласно
`screens-spec.md` §6 и EXPERIENCE.md. Дизайн-решения проверены через
ui-ux-pro-max (карточки/списки/пустые состояния, тач-зоны ≥48dp).

## Что сделано (AL-6)

1. **Активное задание — строго карточка активного состояния.** `WqQuestCard(active = true)`
   рендерится через `WqCardActive` (заливка `accentSoft` = accent @ 8%, рамка
   `accentSoftBorder` = accent @ 35%). Формат по макету: метка-пилюля
   «Активное задание» → что за задание (значок + название) → описание →
   действия. Метка переделана из простого текста в пилюлю по макету `.tlabel`
   (новый семантический токен `accentLabel` = accent @ 14%, текст `accentText`,
   uppercase meta, радиус full). Прогресса по заданию в макете нет — блок
   отсутствует и в данных.
2. **История «Выполненные».** Без изменений по spec §6: подзаголовок
   «Выполненные · N» (meta ink-dim), строки «значок + название» ink-secondary
   + «✓» акцентом; пустое состояние — честная подпись «Пока нет выполненных
   заданий.» (как было, подтверждено прошлым прогоном).
3. **Кнопки выдачи.** Вместо полноширинных primary/ghost — пара кнопок в ряд
   по макету `.tbtn`: новый компонент `WqTaskActionButton` (иконка над
   подписью в колонке, рамка border-strong 1.5dp, радиус md, высота ~64dp,
   тач-зона ≥48dp). Копии строго EXPERIENCE: «Вытянуть карту» и «Выбрать из 6»
   (макетные «Случайное задание» не используются — утверждено ранее).
   Кнопки видны и при активном задании (как в макете): выдача поверх активного
   идёт через диалог подтверждения замены (уже был в 7.4).
4. **Иконки и tint.** Эмодзи-плейсхолдеры макета (🎲/🃏) заменены векторными
   иконками `WalkQuestIcons.Cards` (веер карт — «Вытянуть карту») и
   `WalkQuestIcons.GridSix` (сетка 2×3 — «Выбрать из 6»); tint — токен
   `inkHeadline`. Значки заданий — контентные эмодзи из `QuestCatalog`
   (плейсхолдер по DESIGN, как в 7.4). Добавлены токены `accentLabel` и
   `taskButtonBg` (фон .tbtn: светлая — surfaceRaised по макету, тёмная —
   surfaceSunken); hex только в `ui/theme`.
5. **Данные.** Из `QuestStateStore` (7.4) без правок viewmodel: полей
   `questActive`/`questDone` достаточно.
6. **Прочее.** Подсказка «Задания помогут разнообразить…» теперь плашкой
   `WqCard` по макету `.task-note` и показывается всегда (и с активным
   заданием). «Другое» в действиях активной карточке — только в сегменте
   вкладки (spec §6: «+«Другое» в сегменте»), на оверлее прогулки действий
   два. `_qa/compare-stitch.py` — добавлены id `07-progress-quests-dark/light`
   (по образцу 7.4/7.5).

## On-device сверка (3 состояния × обе темы)

Сценарий: `clear` → `seed-package` (spb-city/v6) → онбординг → Прогресс →
Задания (пустое, а) → Карта → «Начать прогулку» → replay
`_qa/fixtures/sim-walk-ok.track` (20/20) → «+ Задание» (FAB, content-desc
«Задание на прогулку») → «Вытянуть карту» во время записи (задание «Запахи
города» принято в оверлей, запись не остановлена) → «Готово» → «Завершить» +
подтверждение → «На карту» → Прогресс → Задания (активное, б) → «Выполнено»
(история · 1, в). Темы через `cmd uimode night yes/no`; после прогона
возвращена светлая.

Сырые шоты (`_qa/emulator-run/compare-verify/raw/`):

- `07-progress-quests-empty-dark.png`, `07-progress-quests-empty-light.png` — (а) пустое;
- `07-progress-quests-active-dark.png`, `07-progress-quests-active-light.png` — (б) активное;
- `07-progress-quests-history-dark.png`, `07-progress-quests-history-light.png` — (в) история;
- `07-walk-quest-overlay-dark.png` — оверлей прогулки с выданным заданием (бонус).

Склейки (макет ↔ реализация, `_qa/emulator-run/compare-verify/`):

- `07-progress-quests-dark.png` — активное состояние, тёмная тема;
- `07-progress-quests-light.png` — активное состояние, светлая тема.

Структура совпадает: подсказка-плашка → карточка активного задания
(accentSoft-заливка/рамка, пилюля-метка, название, описание, действия) → пара
кнопок выдачи с иконками → «Выполненные · N». Палитры обеих тем по токенам.

## Отступления от макета (обоснованные) и открытые вопросы

1. **Копии кнопок** — «Вытянуть карту»/«Выбрать из 6» вместо макетных
   «Случайное задание»/«Выбрать из 6»: EXPERIENCE важнее макета
   (зафиксировано в compare/README, подтверждено в задаче).
2. **Действия активной карточки** — текст-кнопки «Выполнено» (акцент) /
   «Отказаться» (ink-secondary) по spec §6/§2, а не залитая мини-кнопка из
   макета (Do DESIGN: «одна акцентная заливка на экран»; на экране с активным
   заданием её и так нет). Плюс «Другое» в сегменте — прямо из spec §6.
3. **История без дат** — макет показывает «18 сент» справа; `QuestStateStore`
   хранит только `doneIds` (дат выполнения нет), spec §6 даты не требует.
   Открытый вопрос: добавить timestamps в store отдельной задачей, если даты
   в истории нужны.
4. **Пустое состояние снято без макета** — в `_mock` для 07 есть только
   состояние с активным заданием; сверка пустого — по spec §6 (подсказка,
   две кнопки выдачи, честная пустая подпись истории).
5. **Тень `.tbtn`** из макета (box-shadow 3px) не перенесена: DESIGN — глубина
   тональная, тени только у элементов над картой.
6. **Значки заданий** — эмодзи из `QuestCatalog` (контент каталога). Полный
   перевод 22 значков на вектор — отдельная задача, если потребуется.
7. Склейки готовы к ревью владельцем; при несовпадении — вернуть на доработку.
