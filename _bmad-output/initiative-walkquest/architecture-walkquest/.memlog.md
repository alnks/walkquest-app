- (constraint) PRD §Platform: v1 — нативное Android-приложение, русский язык, тёмная и светлая темы
- (constraint) PRD FR-20/21 + Privacy: треки и история перемещений только на устройстве; сервер получает только ник и агрегированные метрики; облачная синхронизация отклонена, перенос — экспорт/импорт файла
- (constraint) PRD FR-3 + NFR: офлайн-first — карта, трекинг, растуманивание, статистика работают без сети; онлайн нужен только лидерборду и подгрузке POI/регионов
- (constraint) PRD Constraints/Cost: только открытые данные (OSM, Википедия); платные картографические SDK запрещены; Яндекс/2ГИС недоступны по лицензиям; бюджет личный, минимальный
- (constraint) PRD NFR: числовые пороги производительности (fps рендера тумана, расход батареи в час, МБ на регион) фиксируются в этом spine и проверяются прототипом карты
- (direction) Карта должна вести себя как в привычных картографических приложениях: улицы и дворы отрисованы, поворот карты жестом, свободный пан и зум. Это сильный аргумент за векторный GL-движок: поворот и плавный зум растровых тайлов (osmdroid) выглядят заметно хуже
- (constraint) Опыт работы с GIS/картографическими SDK у автора отсутствует — стек должен идти по проторённой дороге: мейнстримная библиотека с живой документацией и примерами, без экзотики
- (question) Q1 открыт: MapLibre GL (качество/плавность, сложнее) vs osmdroid (проще, хуже поворот и стилизация) vs Mapsforge — автор думает над компромиссом скорость-разработки/качество-картинки
- (decision) Картографический движок: MapLibre Native Android (MIT, Maven Central, артефакт org.maplibre.gl:android-sdk). Векторные тайлы OSM, поворот/пинч-зум/плавность — нативно. Туман — кастомный слой с собственной геометрией поверх базовой карты. [принято пользователем 2026-10-01]
- (version) MapLibre Native Android: актуальная линия 13.x (android-v13.5.2, сентябрь 2026, github.com/maplibre/maplibre-native/releases); с 13.0.0 дефолтный бэкенд — Vulkan, при проблемах есть артефакт android-sdk-opengl
- (decision) Бэкенд лидерборда: Supabase, бесплатный тариф. Только лидерборд: ник + агрегированные метрики (расстояние, % по регионам) + механика друзей. Postgres с Row Level Security, REST из коробки. [принято пользователем 2026-10-01]
- (constraint) Supabase Free (проверено 2026-10-01): 500 МБ БД, 50 тыс. MAU, неограниченные API-запросы, 5+5 ГБ исходящего трафика в месяц, проект засыпает после 7 дней неактивности. Трафик слишком мал для раздачи офлайн-пакетов регионов (десятки МБ на скачивание) — пакеты регионов НЕ через Supabase, хостинг пакетов — отдельное решение (GitHub Releases / Cloudflare R2)
- (decision) Пайплайн регионов v1: офлайн-генерация пакетов на машине автора (скрипт: OSM → границы, сетка проходимости, векторные тайлы, POI → единый файл пакета), публикация на бесплатном статическом хостинге. Приложение только скачивает готовое. Серверного пайплайна нет. [принято пользователем 2026-10-01: 'пока нет людей и денег — проще и дешевле'; авто-сборка любого города — желание на будущее]
- (question) Хостинг пакетов регионов: GitHub Releases (бесплатно, без настройки, но медленнее и не CDN) vs Cloudflare R2 (бесплатные 10 ГБ, нулевая плата за отдачу трафика, но нужна регистрация и настройка бакета) — выбрать при дистилляции spine
- (decision) Хранение на устройстве: состояние тумана — компактные битовые карты (один файл на регион, бит = тайл); история прогулок, треки, достижения, задания, настройки — SQLite через Room. Размер тайла НЕ фиксируется: это параметр пакета региона, определяется техническим прототипом (PRD Open Question 2) [рекомендация агента подтверждена пользователем 2026-10-01]
- (decision) Каркас приложения: Kotlin + Jetpack Compose, одна Activity, навигация Compose; паттерн MVVM с однонаправленным потоком данных (UI только рендерит состояние и шлёт события; логика во ViewModel; данные в репозиториях); один gradle-модуль с жёсткими границами пакетов: map, tracking, progress, quests, leaderboard, data [подтверждено пользователем 2026-10-01]
- (decision) Числовые пороги NFR (проверяются техническим прототипом карты до начала зависимых эпиков): ≥30 fps рендера карты с туманом на среднем Android; пакет региона ≤50 МБ; расход батареи при фоновой записи ≤5%/час при выключенном экране; APK ≤30 МБ без пакетов [подтверждено пользователем 2026-10-01]
- (decision) Хостинг пакетов регионов: Cloudflare R2 (бесплатные 10 ГБ, нулевая плата за отдачу); запасной вариант GitHub Releases. Точный выбор — при сборке первого пакета; решение слабо несущее, обратимо
- (constraint) Из UX/content-catalog: модель территории — город/регион/пригород/районы; процентные достижения считаются по городу; друзья в лидерборде — по ссылке-приглашению; синк агрегатов при завершении прогулки и по ручному обновлению (PRD FR-19)
- (version) Kotlin 2.3.10 (май 2026); Jetpack Compose BOM 2026.09.00 (сентябрь 2026, ядро Compose 1.12). Оба проверены 2026-10-01
- (decision) FR-5 (тихое требование при сверке с PRD): точки трека пишутся инкрементально (append-only) во время записи — убийство процесса теряет секунды, а не прогулку; foreground-сервис с постоянным уведомлением
- (event) spine finalized: 10 AD, 3 ревью-линзы PASS (rubric, web-versions, adversarial), lint чист
- (decision) Хостинг пакетов (история 1.4, 2026-10-04): основной подтверждён — Cloudflare R2 (free tier: 10 ГБ хранения/мес, 1 млн Class A и 10 млн Class B операций/мес, egress бесплатен без лимита; публичный доступ через pub-<hash>.r2.dev или свой домен). Запасной — GitHub Releases (ассет < 2 ГиБ, до 1000 ассетов/релиз, без лимита на суммарный размер и трафик). Регистрация бакета — действие человека, чек-лист: tools/region-pack/publish.md
- (decision) URL-схема пакетов для data/packages (история 1.4, 2026-10-04): пакет `<BASE>/region-<regionId>-v<packageVersion>.zip` (имя = regionId/packageVersion из meta.json), стабильный манифест `<BASE>/manifest.json` = { baseUrl, packages: [{ regionId, packageVersion, formatVersion, file, sizeBytes, sha256 архива }] }. Приложение качает манифест → zip → проверяет formatVersion и sha256 архива, затем checksums файлов из meta.json. Новая версия — новый файл, старые не затираются. Запасной: github.com/<owner>/<repo>/releases/download/region-<id>-v<N>/…, манифест ассетом релиза `packages`
- (decision) Хостинг пакетов (история 1.4, 2026-10-04, заменяет решение от того же дня про R2): основной — GitHub Releases вместо Cloudflare R2: Cloudflare требует привязку банковской карты даже для free tier — неприемлемо. URL-схема не меняется, меняется только BASE: `https://github.com/<user>/<repo>/releases/download/<tag>`; zip-пакет и manifest.json — ассеты одного релиза, загрузка через веб-интерфейс github.com без git/gh (publish.md). R2 — альтернатива на будущее, если понадобится CDN/свой домен
- (decision) Состав инструментов region-pack (spike 1.1, проверено PoC на Монако 2026-10-01): Python 3 + planetiler 0.10.2 (portable Temurin JRE, пишет pmtiles напрямую) для tiles.pmtiles; pyosmium + shapely для boundaries.geojson/poi.json/walkability.grid/meta.json; go-pmtiles CLI для верификации. tilemaker отклонён: официальная Windows-сборка v3.0.0 молча падает (exit 127) на машине автора, свежие релизы без Windows-бинарников. osmium-tool отклонён: нет официальных Windows-бинарников, заменён pyosmium.
